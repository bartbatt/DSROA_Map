Deer Springs Ranch Property Map

Using this map without cell service

Add this map to your Home Screen first. On iPhone, a download done in a Safari tab may not be available from the Home Screen icon, so download from the icon instead.

iPhone

  1. Open this map in Safari while on Wi-Fi.
  2. Tap Share (square with arrow) → Add to Home Screen → Add.
  3. Close Safari and open the map from the new DSR Map icon.
  4. Tap ⬇ Download for offline and wait for "Saved for offline use."

Android

  1. Open this map in Chrome while on Wi-Fi.
  2. Tap ⋮ (top right) → Add to Home screen (or Install app).
  3. Open the map from the new DSR Map icon.
  4. Tap ⬇ Download for offline and wait for "Saved for offline use."

At the ranch (no signal)

  1. Open the map from the DSR Map icon.
  2. The background switches to USGS Imagery (works offline) automatically. If it's blank, choose it in the layers menu (top right).
  3. Tap ◎ Show my location to see where you are. GPS works without cell service.

Keeping it current

  1. Every so often, while on Wi-Fi, open the map and tap ⬇ Update offline map to get the latest parcel, road and water system data.

Kane County property-record links in parcel pop-ups need internet.
